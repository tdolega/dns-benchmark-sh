# DNS Benchmark

This repository contains simple tools to perform a DNS query benchmark (performance test) on a random sample of domains.

## Files in the directory

- `top-1m.csv` - A CSV file containing a list of the most popular domains (e.g., top 1 million).
- `prepare_benchmark_file.sh` - A bash script that prepares the domain file for testing. It randomly selects a given number of domains from the CSV, extracts only the domain names, and saves them to a text file.
- `domains.txt` - A text file containing the list of randomly selected domains (generated by the preparation script).
- `benchmark_dns.sh` - The main bash script that runs the DNS resolution speed tests using the `dig` tool.
- `results.jsonl` - A JSON Lines file where the benchmark results are appended after each successful test run.

## How to use?

Both scripts come with a built-in help message. You can view it by running:
```bash
./prepare_benchmark_file.sh --help
./benchmark_dns.sh --help
```

### 1. Prepare the domain sample
First, you need to prepare the file with a sample of random domains. Run the script:

```bash
./prepare_benchmark_file.sh [INPUT_CSV] [OUTPUT_TXT] [NUM_DOMAINS]
```
If you don't provide arguments, the script will use the defaults: `top-1m.csv`, `domains.txt`, and `1000`.

### 2. Run the benchmark
Next, run the main testing script:

```bash
./benchmark_dns.sh [DOMAINS_FILE] [RESULTS_FILE]
```
If you don't provide arguments, the script will use the defaults: `domains.txt`, `results.jsonl`.
   
The script works in two stages:
- First, it tests the first 5 domains with 10-second intervals between queries, displaying the resolution time directly in the console.
- Then, it queries the remaining domains without any delays and records their query times.
- After the test is completed, the script calculates and displays aggregate statistics in milliseconds: **average**, **minimum**, **maximum**, and several **percentiles/quantiles** (p50, p90, p95, p99).
- Finally, the results (along with the machine's hostname and timestamp) are appended as a single JSON object to the results file.

## System requirements

For the scripts to work properly, the following packages must be installed on your system:
- `dig` (usually provided in the `dnsutils` or `bind-utils` package)
- Standard GNU tools: `shuf`, `cut`, `awk`, `grep`, `sort`
